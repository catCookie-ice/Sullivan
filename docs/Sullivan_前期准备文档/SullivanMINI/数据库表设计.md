# SullivanMINI —— 视障公益服务平台 · 数据库表设计

---

## 存储策略

| 数据库 | 存储域 |
|--------|--------|
| **MySQL** | 所有业务数据（每个微服务独享数据库） |
| **Redis** | JWT 缓存、位置数据（Geo）、热点缓存 |

---

## 一、用户域（user-service 数据库）

### 1.1 用户基表 — `user_base`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| uid | BIGINT | **PK**, NOT NULL | 用户唯一ID |
| account | VARCHAR(50) | **NOT NULL**, UNIQUE | 登录账户 |
| password | VARCHAR(255) | **NOT NULL** | 登录密码（BCrypt 哈希） |
| phone | VARCHAR(20) | NULL | 手机号 |
| type | TINYINT | **NOT NULL** | 用户类型（0:监护人, 1:受护人, 2:志愿者） |
| avatar_url | VARCHAR(255) | NULL | 头像 URL |
| created_at | DATETIME | **NOT NULL** | 注册时间 |
| updated_at | DATETIME | **NOT NULL** | 更新时间 |

### 1.2 监护人表 — `guardian`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| uid | BIGINT | **PK, FK → user_base.uid**, NOT NULL | 监护人UID |
| name | VARCHAR(50) | **NOT NULL** | 姓名 |
| emergency_contact | VARCHAR(20) | NULL | 紧急联系电话 |

### 1.3 受护人表 — `protectee`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| uid | BIGINT | **PK, FK → user_base.uid**, NOT NULL | 受护人UID |
| name | VARCHAR(50) | **NOT NULL** | 姓名 |
| disability_type | VARCHAR(50) | NULL | 残障类型 |
| emergency_contact | VARCHAR(20) | NULL | 紧急联系电话 |
| primary_guardian_uid | BIGINT | **NOT NULL, FK → guardian.uid** | 主监护人 |

### 1.4 志愿者表 — `volunteer`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| uid | BIGINT | **PK, FK → user_base.uid**, NOT NULL | 志愿者UID |
| name | VARCHAR(50) | **NOT NULL** | 姓名 |
| region | VARCHAR(100) | NULL | 所在区域（就近匹配） |
| is_available | TINYINT | **NOT NULL** DEFAULT 1 | 是否可接收求助 |

### 1.5 监护-受护绑定表 — `guardian_protectee`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | **PK**, NOT NULL | 自增ID |
| guardian_uid | BIGINT | **NOT NULL, FK → guardian.uid** | 监护人UID |
| protectee_uid | BIGINT | **NOT NULL, FK → protectee.uid** | 受护人UID |
| relationship | VARCHAR(50) | NULL | 关系描述 |
| bound_at | DATETIME | **NOT NULL** | 绑定时间 |

> 一位监护人可绑定多位受护人，一位受护人也可有多个监护人（N:M 关系）。

---

## 二、公益服务域（welfare-service 数据库）

### 2.1 公益机构类型表 — `org_type`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| type_id | INT | **PK**, NOT NULL | 类型编号 |
| type_name | VARCHAR(50) | **NOT NULL** | 类型名称（导盲犬机构、康复机构、辅具机构、慈善机构等） |
| description | VARCHAR(255) | NULL | 描述 |

### 2.2 公益机构表 — `organization`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| oid | BIGINT | **PK**, NOT NULL | 机构唯一ID |
| account | VARCHAR(50) | **NOT NULL**, UNIQUE | 登录账户 |
| password | VARCHAR(255) | **NOT NULL** | 登录密码 |
| type_id | INT | **NOT NULL, FK → org_type.type_id** | 机构类型 |
| org_name | VARCHAR(100) | **NOT NULL** | 机构名称 |
| description | TEXT | NULL | 机构简介 |
| contact_phone | VARCHAR(20) | NULL | 联系电话 |
| address | VARCHAR(255) | NULL | 地址 |
| status | TINYINT | **NOT NULL** DEFAULT 0 | 状态（0:待审核, 1:已认证, 2:已禁用） |
| created_at | DATETIME | **NOT NULL** | 注册时间 |

### 2.3 公益服务项目表 — `welfare_service`

公益机构发布的免费服务项目，供受护人申请。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| wid | BIGINT | **PK**, NOT NULL | 服务项目ID |
| oid | BIGINT | **NOT NULL, FK → organization.oid** | 所属机构 |
| name | VARCHAR(200) | **NOT NULL** | 服务名称（如：导盲犬申请、盲杖申领、康复训练） |
| description | TEXT | NULL | 服务详情 |
| quota | INT | **NOT NULL** | 可服务名额（-1 表示不限制） |
| image_url | VARCHAR(255) | NULL | 配图 |
| status | TINYINT | **NOT NULL** DEFAULT 1 | 状态（0:暂停, 1:开放） |
| created_at | DATETIME | **NOT NULL** | 创建时间 |

### 2.4 服务申请表 — `service_application`

受护人（或监护人代）提交的公益服务申请。

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| aid | BIGINT | **PK**, NOT NULL | 申请ID |
| wid | BIGINT | **NOT NULL, FK → welfare_service.wid** | 申请的服务项目 |
| oid | BIGINT | **NOT NULL, FK → organization.oid** | 所属机构 |
| uid | BIGINT | **NOT NULL, FK → user_base.uid** | 申请人（受护人或监护人） |
| protectee_uid | BIGINT | NULL, **FK → protectee.uid** | 受益受护人（如申请人为监护人代申请） |
| status | TINYINT | **NOT NULL** | 状态（0:待审核, 1:已通过, 2:已完成, 3:已拒绝） |
| remark | VARCHAR(255) | NULL | 申请备注 |
| created_at | DATETIME | **NOT NULL** | 申请时间 |
| processed_at | DATETIME | NULL | 处理时间 |

> 纯公益免费，不涉及任何金额。机构审核通过后，受护人即可获得服务。

### 2.5 公益活动表 — `volunteer_activity`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| vid | BIGINT | **PK**, NOT NULL | 活动ID |
| oid | BIGINT | **NOT NULL, FK → organization.oid** | 发布机构 |
| title | VARCHAR(200) | **NOT NULL** | 活动标题 |
| description | TEXT | NULL | 活动描述 |
| location | VARCHAR(255) | NULL | 活动地点 |
| start_time | DATETIME | **NOT NULL** | 开始时间 |
| end_time | DATETIME | **NOT NULL** | 结束时间 |
| max_volunteers | INT | **NOT NULL** | 最大志愿者人数 |
| status | TINYINT | **NOT NULL** | 状态（0:招募中, 1:进行中, 2:已结束, 3:已取消） |
| created_at | DATETIME | **NOT NULL** | 发布时间 |

### 2.6 志愿报名表 — `volunteer_enrollment`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | **PK**, NOT NULL | 自增ID |
| vid | BIGINT | **NOT NULL, FK → volunteer_activity.vid** | 活动ID |
| uid | BIGINT | **NOT NULL, FK → volunteer.uid** | 志愿者UID |
| status | TINYINT | **NOT NULL** | 状态（0:待审核, 1:已通过, 2:已拒绝, 3:已取消） |
| applied_at | DATETIME | **NOT NULL** | 报名时间 |
| reviewed_at | DATETIME | NULL | 审核时间 |

### 2.7 报警记录表 — `alert_log`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | **PK**, NOT NULL | 报警ID |
| uid | BIGINT | **NOT NULL, FK → protectee.uid** | 发起报警的受护人 |
| guardian_uid | BIGINT | NULL | 已通知的监护人 |
| location_lng | DECIMAL(10, 7) | NULL | 报警时经度 |
| location_lat | DECIMAL(10, 7) | NULL | 报警时纬度 |
| type | TINYINT | **NOT NULL** | 类型（0:手动报警, 1:跌倒检测, 2:求助） |
| status | TINYINT | **NOT NULL** | 状态（0:未处理, 1:已通知监护人, 2:已解决） |
| created_at | DATETIME | **NOT NULL** | 报警时间 |
| resolved_at | DATETIME | NULL | 处理时间 |

### 2.8 通知记录表 — `notification`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | **PK**, NOT NULL | 通知ID |
| receiver_uid | BIGINT | **NOT NULL, FK → user_base.uid** | 接收用户 |
| type | TINYINT | **NOT NULL** | 类型（0:报警通知, 1:活动通知, 2:申请通知, 3:系统通知） |
| title | VARCHAR(200) | **NOT NULL** | 通知标题 |
| content | TEXT | NULL | 通知内容 |
| is_read | TINYINT | **NOT NULL** DEFAULT 0 | 是否已读 |
| created_at | DATETIME | **NOT NULL** | 发送时间 |

## 三、导航域（navigation-service 数据库）

### 3.1 模型登记表 — `model_registry`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| model_id | INT | **PK**, NOT NULL | 模型编号 |
| model_name | VARCHAR(100) | **NOT NULL** | 模型名称（如 yolov8n-seg） |
| model_path | VARCHAR(255) | **NOT NULL** | 模型文件路径 |
| category | TINYINT | **NOT NULL** | 类型（0:全景分割, 1:语音识别） |
| status | TINYINT | **NOT NULL** DEFAULT 1 | 状态（0:下线, 1:上线） |
| created_at | DATETIME | **NOT NULL** | 创建时间 |

### 3.2 导航日志表 — `navigation_log`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| log_id | BIGINT | **PK**, NOT NULL | 日志ID |
| uid | BIGINT | **NOT NULL** | 受护人UID |
| obstacle_type | VARCHAR(50) | NULL | 识别到的障碍物类型 |
| obstacle_distance | DECIMAL(5, 2) | NULL | 障碍物距离（米） |
| guide_text | VARCHAR(500) | NULL | 生成的引导文本 |
| location_lng | DECIMAL(10, 7) | NULL | 当前经度 |
| location_lat | DECIMAL(10, 7) | NULL | 当前纬度 |
| process_time_ms | INT | **NOT NULL** | 单帧处理耗时（毫秒） |
| created_at | DATETIME | **NOT NULL** | 创建时间 |

> **索引建议：** `{ uid, created_at }` 复合索引，支持查询用户的导航历史。

## 四、管理域（admin-service 数据库）

### 4.1 管理员类型表 — `admin_type`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| type_id | INT | **PK**, NOT NULL | 类型编号 |
| type_name | VARCHAR(50) | **NOT NULL** | 类型名称（超级管理员 / 运营人员） |

### 4.2 管理员基表 — `admin_base`

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| cid | BIGINT | **PK**, NOT NULL | 管理员ID |
| account | VARCHAR(50) | **NOT NULL**, UNIQUE | 登录账户 |
| password | VARCHAR(255) | **NOT NULL** | 登录密码 |
| type_id | INT | **NOT NULL, FK → admin_type.type_id** | 管理员类型 |
| name | VARCHAR(50) | NULL | 姓名 |
| status | TINYINT | **NOT NULL** DEFAULT 1 | 状态 |
| created_at | DATETIME | **NOT NULL** | 创建时间 |

## 五、关系总览

```
┌─ MySQL ────────────────────────────────────────────────────────────┐
│                                                                      │
│  user-service 数据库                                                 │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │  user_base (uid, type)                                         │ │
│  │    ├── guardian (uid)                                          │ │
│  │    ├── protectee (uid) ── primary_guardian_uid ──→ guardian    │ │
│  │    │     └── guardian_protectee                                │ │
│  │    └── volunteer (uid)                                         │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                                                                      │
│  welfare-service 数据库                                              │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │  organization (oid, type_id)                                   │ │
│  │    ├── welfare_service (wid) ←──┐                              │ │
│  │    │     └── service_application (uid → user_base.uid)         │ │
│  │    └── volunteer_activity (vid) │                              │ │
│  │              └── volunteer_enrollment (uid → volunteer.uid)    │ │
│  │  alert_log (uid → protectee.uid)                               │ │
│  │  notification (receiver_uid → user_base.uid)                   │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                                                                      │
│  navigation-service 数据库                                           │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │  model_registry                                                │ │
│  │  navigation_log (uid, created_at)                              │ │
│  └────────────────────────────────────────────────────────────────┘ │
│                                                                      │
│  admin-service 数据库                                                │
│  ┌────────────────────────────────────────────────────────────────┐ │
│  │  admin_type ── admin_base                                      │ │
│  └────────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

**总计：16 张表**，覆盖 4 个业务域。全程不涉及商业交易，纯公益定位。
