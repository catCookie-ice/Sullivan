## 二、核心业务信息流详解

### 2.1 ⭐ 全景分割视觉辅助出行

```mermaid
sequenceDiagram
    participant Phone as Android 端
    participant GW as API Gateway
    participant NS as navigation-service
    participant DB as MySQL

    loop 每帧处理（≥10FPS）
        Phone->>Phone: Camera2 采集帧
        Phone->>Phone: 压缩至 640x480
        Phone->>GW: POST /api/navigation/analyze-frame
        GW->>NS: 转发推理请求
        NS->>NS: ① 全景分割推理<br/>(ONNX Runtime)
        NS->>NS: ② 空间分析<br/>距离/方位/运动趋势
        NS->>NS: ③ 生成语音引导文本
        NS-->>GW: 返回引导指令
        GW-->>Phone: 返回 { guide_text, obstacles[] }
        Phone->>Phone: TTS 播报引导
        NS->>DB: 异步写入 navigation_log
    end
```

### 2.2 语音指令控制

```mermaid
sequenceDiagram
    participant Phone as Android 端
    participant GW as API Gateway
    participant NS as navigation-service

    Phone->>Phone: SpeechRecognizer 监听
    Phone->>GW: POST /api/navigation/voice-command
    GW->>NS: 转发语音指令
    Note over NS: 指令解析：<br/>"呼叫监护人" / "启动导航" / "停止导航" / "我要报警"
    NS-->>GW: 返回 { action, params }
    GW-->>Phone: 返回指令解析结果
    Phone->>Phone: 执行对应操作
```

### 2.3 安全报警 → 通知监护人

```mermaid
sequenceDiagram
    participant P as 受护人 Android 端
    participant GW as API Gateway
    participant WS as welfare-service
    participant US as user-service
    participant G as 监护人

    P->>GW: POST /api/alert/create
    GW->>WS: 创建报警
    WS->>US: 查询受护人绑定的监护人
    US-->>WS: 返回监护人列表
    WS->>WS: 写入 alert_log
    WS-->>GW: 报警创建成功
    GW-->>P: 返回结果

    Note over WS,G: 异步通知
    WS-->>G: 推送报警通知（含位置信息）
    G->>G: 打开地图查看受护人位置
```

### 2.4 公益服务申请流程

```mermaid
sequenceDiagram
    participant U as 受护人/监护人
    participant WS as welfare-service
    participant Org as 公益机构

    U->>WS: 浏览公益服务项目
    WS-->>U: 返回服务列表
    U->>WS: 提交服务申请
    WS->>WS: 校验名额 → 扣减
    WS-->>U: 申请提交成功（待审核）

    Note over U,Org: 机构审核
    Org->>WS: 审核申请
    WS->>WS: 状态 → 已通过 / 已拒绝
    WS-->>U: 推送审核结果通知

    Note over U,Org: 服务完成
    Org->>WS: 完成服务
    WS->>WS: 状态 → 已完成
    WS-->>U: 推送完成通知
```

### 2.5 公益活动 → 报名 → 审核

```mermaid
sequenceDiagram
    participant Org as 公益机构
    participant WS as welfare-service
    participant Vol as 志愿者

    Org->>WS: 发布公益活动
    WS->>WS: 写入 volunteer_activity（招募中）

    Vol->>WS: 报名活动
    WS->>WS: 写入 volunteer_enrollment（待审核）
    WS-->>Vol: 报名成功，等待审核

    Org->>WS: 审核通过
    WS->>WS: status → 已通过
    WS-->>Vol: 推送审核通过通知
```

## 三、数据存储映射

| 业务数据 | 存储位置 | 读写模式 | 说明 |
|---------|---------|---------|------|
| 用户账户/资料 | MySQL | 频繁读写 | user-service 独享 |
| 公益机构信息 | MySQL | 中等频率 | welfare-service 独享 |
| 公益服务项目 | MySQL | 读多写少 | 受护人浏览为主 |
| 服务申请 | MySQL | 写入 + 查询 | 申请→审核→完成闭环 |
| 志愿活动 | MySQL | 中等频率 | 读写均衡 |
| 报警记录 | MySQL | 追加写入 | 只读历史 |
| 通知记录 | MySQL | 写入 + 按用户拉取 | 站内通知 |
| 导航日志 | MySQL | 追加写入 | 统计分析 |
| 模型配置 | MySQL | 极少写入 | 启动时加载 |
| JWT 会话 | Redis | 高速读写 | 过期自动淘汰 |
| 位置数据 | Redis Geo | 频繁写入 + 地理查询 | 实时位置 |
