## 2. 完成内容

### 2.1 数据模型（V3 迁移，只追加、全幂等）

新增 `V3__welfare_activity_volunteer_realtime.sql`：

- `guardian_binding` 追加 `requested_by`（发起方账号 ID，历史行回填为 `guardian_uid`）。
- `volunteer_activity`：新建表含 `location_lng/location_lat DECIMAL(10,6)`、`registration_starts_at/registration_ends_at`；已存在表用 `information_schema` 动态 `ALTER` 追加（存量表新列加为 NULL，应用层必填校验）。CHECK：`registration_starts_at <= registration_ends_at <= starts_at`。
- `activity_enrollment`、`volunteer_application`（`effective_key` 唯一防重复 PENDING）、`realtime_session`（`session_type` CHECK 仅 `BASIC`）。
- 权限码 `VOLUNTEER_REVIEW` 统一走 `AdminSeedInitializer`（自动授予 `SUPER_ADMIN`）。

### 2.2 绑定双向同意（`BindingService` + `/api/v1/bindings`）

- 双向发起：`targetRole=PROTECTEE` 调用者须 `GUARDIAN`；`targetRole=GUARDIAN` 调用者须 `PROTECTEE`。
- 接收方（非发起方）确认/拒绝；发起方取消；任一方解除 `ACTIVE`（`permanent_flag=true` 返回 403）。
- 主绑定解除后按 `confirmed_at ASC, id ASC` 提升最早其余 `ACTIVE` 为主绑定。
- 定时任务每日将超 7 天未处理的 `PENDING` 置 `EXPIRED`。
- 旧 `/guardians/bindings` 保留为兼容别名（`LegacyBindingRequest` 转换）。

### 2.3 志愿者兼任申请与管理员审核

- `VolunteerApplicationService`：提交（校验 GUARDIAN 角色、未持 VOLUNTEER、注册时长）、我的申请、撤销、管理员分页查看、审核通过/拒绝。
- 注册时长限制配置 `app.volunteer.min-registration-days`（默认 90），提交与审核两处校验（不足报"还差 N 天"）。
- 审核通过事务内幂等追加 `VOLUNTEER` 角色（`grantVolunteerRole`）；申请人须重新登录刷新 JWT 角色。
- `POST /users/me/roles/volunteer` 语义由"立即授角色"改为"提交申请"。

### 2.4 机构创建志愿活动

- `VolunteerActivityService`：机构 `APPROVED` 校验、`starts_at > now`、报名窗口合法、经纬度同空或同非空且越界校验、状态固定 `RECRUITING`。
- `POST /activities`、`GET /activities/mine`、`GET /activities`（公开，默认只出 RECRUITING，不含报名者清单）。

### 2.5 监护-受护实时会话（长连接）

- 新增 `spring-boot-starter-websocket`；端点 `/ws/realtime`。
- `realtime` 包：`ConnectionPool`（接口，C++ 重构缝）+ `InMemoryConnectionPool` + `RealtimeChannel` + `RealtimeEnvelope`（JSON 信封）+ 握手拦截器（`?token=` 或 `Sec-WebSocket-Protocol` 子协议鉴权）+ WebSocket 处理器。
- REST：`POST/GET /realtime/sessions`、`/{id}/accept|reject|end`。
- 中继授权：每次转发校验 `fromUid == 令牌主体`、双方为会话参与人、双方仍存在 `ACTIVE` 绑定（绑定解除后拒绝转发）。
- `session_type` 仅 `BASIC`；`VOICE/CAMERA/LOCATION` 为 `[FULL]` 扩展，登记入 `16`。

### 2.6 前端（三个 Web 项目）

- **user-web**：绑定管理页重写（我的绑定/收到请求的确认拒绝/发起双向绑定）；新增志愿者申请页（提交/撤销/状态，提示重登刷新角色）；新增实时会话演示页（创建/接受/拒绝/结束 + WebSocket 连接与双向中继收发）；`/ws` 代理（ws:true）。
- **admin-web**：新增志愿者兼任审核页（状态筛选、注册天数、通过/拒绝必填原因）；菜单按 `VOLUNTEER_REVIEW` 权限显隐。

## 3. 关键问题与处理

- **MyBatis-Plus lambda 缓存**：纯 Mockito 单测不加载 Spring，新增实体（`RealtimeSession`/`VolunteerApplication`）的 lambda 缓存未初始化导致 `can not find lambda cache`；在测试 `@BeforeAll` 用 `TableInfoHelper.initTableInfo` 手动初始化解决。
- **旧绑定方法迁移**：`requestBinding/acceptBinding/addVolunteerRole` 从 `RegistrationService` 迁出（绑定→`BindingService`，兼任→`VolunteerApplicationService`），旧路径保留兼容别名，避免破坏已联调前端。
- **`BindingResponse` 增加 `requestedBy`**：同步更新前端类型与既有构造调用点。
- **高德 key 未配置**：`useAmap` 在缺少 `VITE_AMAP_KEY` 时抛错，`AmapPicker` 显示配置提示，不阻塞页面其他功能。
