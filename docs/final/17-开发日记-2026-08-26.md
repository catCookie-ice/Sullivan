## 2. 完成内容

### 2.1 三前端墨线笔记本涂鸦主题（`global.scss` 四份逐字节一致）

- **设计令牌**（`:root`）：米白纸感底色 `--paper:#fbf9f2` / 卡片暖白 `--paper-card:#fffdf8` / 墨棕线条 `--ink:#3f3a32` 与递浅 `--ink-2..5`；低饱和功能色小面积点缀：雾蓝 `--mist:#5f7a92` / 苔绿 `--moss` / 芥末黄 `--mustard` / 陶土红 `--terra`（取中暗度，保证对比度 ≥4.5:1 的无障碍软约束）。
- **两层覆写策略**：① `:root` 覆盖 `--el-*` 变量（色板/文字/边框/圆角/阴影/遮罩/菜单）；② `body ` 前缀非 scoped 选择器覆写组件 DOM（特异性 `(0,1,1)` 恒压 EP 的 `(0,1,0)`），规避 `unplugin-vue-components` 注入的组件级 CSS 顺序风险。
- **纸感背景**（纯 CSS 无图片）：`body` 三层背景 = feTurbulence 颗粒噪声（opacity 0.05）+ 每 32px 横格线 + 两团纸浆晕染，`background-attachment:fixed`。
- **组件手绘化**：卡片非对称圆角 `border-radius:14px 6px 16px 8px / 8px 16px 6px 14px` + 双框错位 box-shadow + 虚线 outline；菜单便签条（`--paper-tint` 底、奇偶行交错旋转、激活波浪下划线 SVG data URI）；表格线稿化（表头浅纸 + 手写体，去灰块）；**主按钮浅雾蓝纸底 + 墨棕描边 + 雾蓝深字**（低饱和，非大色块）；输入聚焦雾蓝线 + 手绘错位外框；dialog/message/popper/empty/result 等全纸感。
- **中文手写体**：三端 `index.html` 引入站酷快乐体 + 马善政楷体（`fonts.loli.net` 国内镜像，`unicode-range` 子集 + `display=swap`，加载失败回退系统字体）。
- **布局 ×4**：横向菜单改手绘便签条，左侧品牌涂鸦标识（墨圈 + 波浪下划线），`.content` 背景透明让纸纹透出。

### 2.2 404 侦探放大镜（三端一致）

- 整页 `backdrop-filter: blur(10px) saturate(1.15)` 高斯模糊营造磨砂质感。
- 跟随光标的侦探放大镜（墨棕圆环 + 高光 + 陶土红十字准星 + 木纹手柄），触屏 touchmove 支持。
- 磨砂层用 `mask-image: radial-gradient` 在镜孔处**镂空** → 镜内清晰、镜外磨砂；`pointer-events:none` 不挡按钮。

### 2.3 新建受护人测试端 `client-web/protectee-web`

- 独立自包含项目（端口 **5177**），复制 user-web 骨架，去掉 `@amap` 依赖；`global.scss` / `NotFound.vue` 与三端逐字节一致。
- API 精简：`login`、`bindings`（受护人双向：申请监护人 / 确认 / 拒绝 / 取消 / 解除）、`lookup`、`activities`（新增公开列表只读）、`realtime`、找回密码/联系方式。
- 页面：登录（USER 主体 + 找回联系方式提醒）、找回密码、**绑定管理**（我的绑定 / 申请监护人 / 用户查找）、**活动浏览**（公开活动只读）、**实时会话**（WebSocket 演示，复制 user-web）。
- 受护人不可用能力（注册、志愿者兼任、活动报名、报警/位置/公益服务）未在端内展示。

## 3. 关键问题与处理

- **Element Plus 样式注入顺序**：`ElementPlusResolver` 会给每个组件注入组件级 CSS，可能排在 `global.scss` 之后反压覆写。用 `body ` 前缀提升特异性恒定压过（`(0,1,1)` > `(0,1,0)`），与加载顺序解耦；teleport 到 body 的 dialog/message/popper 同样命中。
- **旧硬编码色清零**：全仓库 `#f5f7fa / #0d1117 / #c9d1d9 / #909399` 12 处改为主题变量/透明，`grep` 清零验证。
- **RealtimeDemo 深色日志卡**：`#0d1117` GitHub 深色与涂鸦主题冲突，改为墨色纸反白（`--ink` 底 + 米白字 + 手绘圆角）。
- **AmapPicker**：`#909399` tip 换 `--ink-3`，地图容器加手绘边框。
- **受护人无法自助注册**：`/auth/register/user` 仅允许 GUARDIAN/VOLUNTEER，测试端登录页无注册入口，账号需监护人先在 user-web 创建。
