# SullivanMINI 开发日记：2026-08-12

**开发主题:** 找回联系方式（半加密两段存储）与找回密码验证、未设置联系方式的登录提醒  
**适用范围:** SullivanMINI `[MINI]`  
**关联里程碑:** M2 Java 身份与权限（补充）、M7 Web 角色页面与治理（补充）

## 1. 今日目标

为自然人与机构增加可选"找回手机号/邮箱"能力，实现找回密码的前置验证环节，并对未设置找回联系方式的账号提供登录提醒。全程不修改已有表，新增独立找回表；不引入第三方依赖。

## 2. 完成内容

### 2.1 数据模型（新表，不修改已有表）

- 新增 Flyway 迁移 `V2__account_recovery.sql`，两张表：
  - `account_recovery`：找回联系方式，每主体每方式一行。`prefix` 为明文不加密段，`cipher_hash` 为剩余段单向加密（HMAC-SHA256，key=prefix）；`principal_type`+`principal_id`+`recovery_type` 唯一。
  - `account_recovery_reminder`：提醒状态，每主体一行，`remind_never`（不再提醒）与 `last_reminded_at`（下次再说时间）。
- 新增领域对象与 Mapper：`AccountRecovery`、`AccountRecoveryReminder` 及对应 Mapper。

### 2.2 半加密方案（单向加密）

- 新增 `common/RecoveryContactCodec`：
  - 手机号：后四位明文，前段加密；
  - 邮箱：`@` 前 local 段前 1/4（最多 4 字符）明文，其余（剩余 local + `@域名`）加密；
  - 不加密段即 HMAC-SHA256 的密钥，密文不可逆；验证时按同规则重算比对。
- 存储分为两段：明文 `prefix` + 单向加密 `cipher_hash`。

### 2.3 注册与登录改造

- `UserRegisterRequest` / `OrganizationRegisterRequest` 新增可选 `recoveryPhone` / `recoveryEmail`（留空合法，格式非法 400；受护人注册不包含该字段）。
- `RegistrationService` 注册成功后将联系方式写入找回表（自然人与机构）。
- `TokenResponse` 新增 `recoveryReminder`：登录时按"未设置任何找回联系方式且未到提醒间隔"计算；管理员恒为 `false`。

### 2.4 找回密码接口（验证到"补全验证"一步）

新增 `RecoveryController` / `RecoveryDtos` / `RecoveryService`：

| 接口 | 认证 | 说明 |
|---|---|---|
| `POST /auth/password-recovery/start` | 公开 | 按登录名返回可用找回方式与掩码前缀；账号不存在/未设置返回空列表 |
| `POST /auth/password-recovery/verify` | 公开 | 补全后按同规则重算比对，返回 `verified`（邮箱大小写不敏感） |
| `GET /auth/me/recovery` | 登录 | 我的找回联系方式状态 |
| `PUT /auth/me/recovery` | 登录 | 设置/更新（手机号与邮箱至少一个） |
| `POST /auth/me/recovery/remind-later` | 登录 | "下次再说"：记录时间，满一周再提醒 |
| `POST /auth/me/recovery/dismiss` | 登录 | "不再提醒" |

发送验证码与重置密码按需求**留空**。

### 2.5 前端（org-web 与 user-web 各一份）

- 新增注册页 `/register`：含找回手机号/邮箱输入框与"留空将导致密码无法找回"提示。
- 新增找回密码页 `/forgot-password`：登录名 → 选择方式（显示掩码前缀）→ 补全 → 验证结果（后续留空）。
- 登录页：底部新增"注册"与"忘记密码？"入口；登录后若 `recoveryReminder=true` 弹出提醒（去设置 / 下次再说 / 不再提醒）。
- 路由守卫放行 `/register` 与 `/forgot-password`。

### 2.6 安全与脱敏

- 联系方式在数据库中不存完整明文，仅明文不加密段 + 单向加密哈希。
- 找回接口不暴露账号是否存在（未找到或未设置均返回空列表）。
- 仓库无硬编码密钥；`.env` 含数据库口令，由根 `.gitignore` 排除，本次未提交任何密钥。

## 3. 关键问题与处理

- **MyBatis-Plus 3.5.7 的 `insert(Collection)` 重载**：单元测试中 `verify(mapper).insert(any())` 出现重载歧义，改用显式类型捕获（`ArgumentCaptor` + 强转）解决。
- **邮箱不加密段长度的取整**：`local.length()/4` 向上取整且最多 4 字符，短邮箱至少保留 1 个字符，保证掩码可读。
- **受护人不纳入找回**：受护人由监护人创建，不开放自注册该字段，符合"不含受护人"的要求。
