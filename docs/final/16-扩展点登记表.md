# SullivanMINI 扩展点登记表

**文档版本:** v1.0（模板）
**建立日期:** 2026-07-26
**维护要求:** 每阶段完成时增量登记，见 `15` §2.3 与 §8 第 5 条
**权威关系:** 本文属 README 权威顺序第 7 层。预留合规性以 `00` §6.2 与 `05` §6 为准。

## 0. 这张表是给未来的我们看的

半年后没人记得当初为什么留了某个接口。没有这张表，预留工作等于白做 —— 接完整版时找不到扩展点，只能重新读一遍代码。

**填表规则：**

- 每个预留点一行，在对应阶段完成时登记，不要事后补。
- "当前被引用"必须为 **否**。若为是，说明预留已形成运行依赖，违反 `00` §6.2 第 1 条，需回退。
- "启用条件"要写清前置动作，至少包括是否需要走 `00` §8 的基线变更。
- M7 集中复核一次，见 `15` §4 的 M7 节。

## 2. 禁止项区

以下是**禁止性预留** —— 明确记录"不能做什么"，防止未来以"扩展"名义违反已有裁决。这一区只增不改，每条都附裁决出处。

| # | 禁止内容 | 出处 | 说明 |
|---|---|---|---|
| N-01 | 不得向公益服务/活动/申请/报名表追加金额、币种、价格、订单、钱包、结算字段 | `00` §6.2 第 2 条、`05` §6 | 未来商业能力建独立 `commerce`/`payment`/`settlement` schema 与独立账本 |
| N-02 | 不得使用 `reserved_1`、`reserve1`、`extra1` 等无语义占位字段 | `05` §6 | 新字段须写明未来业务主体、数据来源、读写服务、数据分类、启用版本、迁移回滚方案 |
| N-03 | 不得向 `navigation_sample_event` 写入原始图像帧、TTS 音频或逐帧视频日志 | `05` §3.4、`00` §7 第 6 条 | 未来视频通话走独立 realtime-media 模块及短保留媒体元数据 |
| N-04 | 不得复用 `notification` 表作为聊天消息表 | `05` §6 | 未来聊天建独立 messaging schema |
| N-05 | 不得让 `model_version` 承担 AI 客服模型登记或计费 | `05` §6 | 该表仅服务导航模型；未来客服模型另建表与计量模块 |
| N-06 | 不得重新按业务模块拆 schema 或引入跨服务写入 | `00` §4.5、`05` §1、`06` §5 | 当前使用统一数据库；Java 是业务数据唯一写入方，Python 只访问导航表 |
| N-07 | 不得在 MINI 的权限集/菜单中出现 `[FULL]` 权限码或入口 | `00` §6.2 第 3 条 | 菜单驱动机制可预留，但不得渲染出点不进去的入口 |
| N-08 | 不得让 API 返回伪成功或静态演示数据冒充 `[FULL]` 能力 | `00` §6.2 第 4 条 | — |
| N-09 | 不得把权限、状态、金额、币种或任何安全决策藏入 `extension` JSON | `05` §5 | 需检索或约束的扩展字段必须升级为具名列并迁移 |
| N-10 | 不得在服务端生成或存储导航 TTS 音频 | `00` §5、`01` FR-09 | TTS 由 Android 本地 `TextToSpeech` 执行 |
| N-11 | 不得用 LLM 生成导航引导文本 | `00` §6.1、`13` §3.5 | 安全关键路径要求可预测可穷举；`GuideTextGenerator` 接口虽可扩展，启用须先走 `00` §8 基线变更 |
| N-12 | 不得因"预留"要求用户支付或要求机构充值 | `00` §3 | MINI 全程免费 |
| N-13 | 不得加评分、评价、抽成等级字段 | `00` §6.1 | 前期完整版的 `commission_tier` 属 `[FULL]` |
| N-14 | 不得现在就把 `[FULL]` 枚举值加入 MINI 可达状态或可选项 | `02` §1 | 允许注释说明扩展点，不允许加值 |

## 3. 合规自检

M7 执行，对应 `00` §6.2 五条约束与 `15` §4 的 M7 核查表。

1. 删除或注释 §1 全部预留点后，MINI 能正常启动、全部测试通过。**这是预留未形成运行依赖的判定标准。**
2. §1 全部行的"当前被引用"均为否。
3. §2 全部禁止项无违反；N-01、N-06 用 `14` §5 的数据库检查验证。
4. `[MINI]` 完成度统计中不含任何预留点或 `[FULL]` 能力（`00` §7 第 9 条）。
