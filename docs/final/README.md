## 1. 使用说明

本目录是项目设计与开发的唯一权威文档集。根目录及 `SullivanMINI/` 下的原文档仅作为需求来源和历史参考；内容冲突时，以本目录文档为准。

当前迭代只交付 SullivanMINI 的公益能力。完整版的商业交易、AI 客服、群聊、视频通话等能力仅做边界、接口和数据扩展预留，不属于当前验收范围，也不得因预留而引入当前运行依赖。

## 5. 当前事实

截至 2026-08-04，Java 后端已实现注册、登录、JWT、监护绑定、角色兼任、管理员注册码和最高管理员 bootstrap；单元测试、JAR 打包及本机 MySQL 真实启动验证已通过。位置、报警、导航、公益闭环和完整 HTTP 端到端验收仍按 `15` 推进。当前 Flyway 可执行迁移为 `V1__registration_identity.sql`，旧领域迁移目录尚未完成清理或合并。

截至 2026-08-12，新增找回联系方式能力（`V2__account_recovery.sql`）：自然人与机构注册可选 `recoveryPhone`/`recoveryEmail`，联系方式按"明文不加密段 + HMAC-SHA256 单向加密段"两段存储；找回密码流程已实现到"按掩码前缀补全并验证"一步（发送验证码与重置密码留空）；未设置联系方式的账号登录返回 `recoveryReminder` 提醒，支持"下次再说"（一周后）与"不再提醒"。详见 `17-开发日记-2026-08-12.md`。

截至 2026-08-17，新增 `V3__welfare_activity_volunteer_realtime.sql`：绑定双向同意（受护人可主动申请绑定监护人、接收方确认/拒绝、发起方取消、永久绑定不可解除、定时过期）、志愿者兼任申请与管理员审核（`VOLUNTEER_REVIEW` 权限 + 注册满 N 天可配置限制）、机构创建志愿活动（报名窗口 + 高德经纬度）、监护-受护实时会话（WebSocket `/ws/realtime` + 连接池，`BASIC` 类型），以及 org-web 高德地图选点组件（`VITE_AMAP_KEY` 由用户在环境配置补全）。详见 `17-开发日记-2026-08-17.md`。
