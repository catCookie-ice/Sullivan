### 2.2 对象查找接口（按唯一标识）

- 新增 `LookupController` / `LookupService` / `LookupDtos`。
- `GET /api/v1/users/{id}`：志愿者、监护人、受护人统一按自然人账号查找，返回 `roles` 与 `alsoVolunteer`（是否兼任志愿者）。
- `GET /api/v1/organizations/{id}`：机构查找。
- `GET /api/v1/admins/{id}`：管理员查找，要求 `ADMIN_MANAGE` 权限。
- 按约定将 `ADMIN_MANAGE` 同时授予 `HR_ADMIN`（读权限），并同步更新 `docs/03` 权限矩阵。

### 2.3 管理端用户与机构管理

- 新增权限 `USER_MANAGE`（用户管理）与 `ORG_MANAGE`（机构管理），授予最高管理员与运营管理员。
- 新增 `AdminManagementController` / `AdminManagementService` / `AdminManagementDtos`。
- `GET/DELETE /api/v1/admin/users`：分页用户列表（角色过滤 + 关键字搜索）、逻辑删除用户。
- 删除兼任志愿者的监护人时仅撤销其 `VOLUNTEER` 角色（`action=VOLUNTEER_ROLE_REVOKED`），账号保留；其余情况逻辑删除整个账号。
- `GET/DELETE /api/v1/admin/organizations`：机构列表（状态过滤）与逻辑删除。
- 逻辑删除基于 MyBatis-Plus `@TableLogic` 的 `deleted_at`，删除后登录、查找、列表均不再可见。

### 2.4 时间格式化工具

- 新增 `common/TimeUtil`：统一 `yyyy-MM-dd HH:mm:ss` 格式，含日期/时间/毫秒格式化与宽松解析，全部 null 安全。
- 新增 `JacksonConfig`：`LocalDateTime`/`LocalDate`/`LocalTime` 全局序列化与反序列化。
- 统一后请求时间字段（如注册码 `expiresAt`）须传 `yyyy-MM-dd HH:mm:ss`，旧的 ISO `T` 分隔格式不再接受。

### 2.5 前端三项目拆分

  - `org-web`（机构端，5174）、`user-web`（监护+志愿者端，5175）、`admin-web`（管理端，5176）。
- 公共代码（请求封装、auth store、类型、全局样式、登录页、404 页）按各项目复制一份。
- 登录页固定本端 `principalType`（机构=ORGANIZATION、自然人=USER、管理员=ADMIN）。
- 已为已实现的后端接口接入真实页面：机构资料、绑定管理（创建受护人/发起绑定/接受绑定/用户查找）、兼任志愿者、管理端用户/机构列表与删除、注册码创建；未实现接口保留占位页。

### 2.6 前端代理修复（登录 500）

- 根因：`server-java/.env` 中 `SERVER_PORT=8642`，而 `vite.config.ts` 编译产物 `vite.config.js`（旧配置指向 8080）优先级高于 `.ts`，导致 dev 代理转发到 8080（后端不在该端口）→ 前端登录 500，而 Swagger 直连 8642 正常。
- 清理编译产物，`tsconfig.json` 加 `noEmit`、`tsconfig.node.json` 设 `outDir` 到 `node_modules/.tmp`，杜绝 `vite.config.js` 覆盖配置。
- 三个前端代理目标固定写死为 `http://127.0.0.1:8642`；不再读取后端 `.env` 或任何后端文件，前端仅通过 HTTP 请求访问后端。

### 2.7 安全与脱敏

- 仓库 `application.properties` 全部使用环境变量占位符（`${VAR:default}`），无硬编码密钥。
- `.env`、`node_modules`、`dist`、`.vite`、`*.pem`、`*.key` 等均由根 `.gitignore` 排除。
- 本次推送前已扫描待提交文件，无明文密码、密钥或令牌。

## 3. 关键问题与处理

- **springdoc 丢弃 `LocalDateTime` 的 `example`**：Swagger 契约中时间字段仅显示 description（已注明格式），这是 springdoc 对 `date-time` 字段的既有行为，不影响使用。
- **逻辑删除 + 唯一索引**：被逻辑删除的用户/机构登录名不可立即复用（重注册同名会 409），属预期。
- **代理端口不匹配**：后端端口变更时前端需同步；现已在 vite 配置固定为 8642，后端 `application.properties` 默认端口同样改为 8642。
